# 新项目资料清单（开工核对用）

## 用法

1. 新项目开始时完整读本文件。
2. 逐项核对 A 级（必备）；缺失项先问用户，用户无法提供时记录为假设并写入交付说明。
3. B 级影响"实景感"上限，C 级决定"照片级"能力——主动提醒用户提供。

## A 级：必备资料

| # | 资料 | 要求 | 缺失后果 |
|---|---|---|---|
| A1 | 施工图/初设图纸 PDF | 可搜索文字层优先；含平面图、桥型布置图、一般构造图、逐桩坐标表；CAD(dwg) 更佳 | 只能示意，无法照图建模 |
| A2 | 项目简介/设计说明 | 项目名称、新建/重建/扩建、规模 | 影响建模范围与成果口径 |
| A3 | 坐标锚点 | 桥中心/交点/控制点坐标；最佳为逐桩坐标表（桩号,X,Y） | 无法与真实地图对齐 |
| A4 | 坐标系说明 | 如 CGCS2000 高斯 3°带 中央子午线 114°；或直接给经纬度 | 坐标换算必错 |
| A5 | 结构几何参数 | 跨径布置、桥宽、梁高（根部/跨中）、墩型、路线/桥梁全长、起终点桩号 | 模型为示意级 |

## B 级：强烈建议（实景感上限）

| # | 资料 | 用途 |
|---|---|---|
| B1 | 现场照片 8~15 张 | 四方向看桥/道路、引道、河道、地标建筑；注明拍摄位置与朝向 |
| B2 | 无人机照片/倾斜摄影模型 | OSGB/OBJ/FBX，可替换合成底，接近实景 3D |
| B3 | 现状旧桥/拆除说明 | 旧桥与新建平面关系、拆除范围 |
| B4 | 用途与视角清单 | 报审/汇报/宣传；要哪些视角 |
| B5 | 效果图风格意向 | 参考风格 |

## C 级：可选加分（质量质变）

| # | 资料 | 说明 |
|---|---|---|
| C1 | 设计三维模型 | Revit/Civil3D/Midas/CATIA 导出 FBX/OBJ/glTF/IFC/3D DWG——最有效一项，配 Blender Cycles |
| C2 | 纵断面高程表/地形 | 精确标高、净空、坡度 |
| C3 | 天地图/高德 Key | 备选影像与注记；没有用免费瓦片 |
| C4 | 桥名等文字 | 桥名牌与图面标注 |

## 关键信息明细（对应图纸位置）

| 关键信息 | 图纸来源 | 用途 |
|---|---|---|
| 桩号系统、起终点桩号 | 总说明/平面图 | 3D 长度与桩号刻度 |
| 逐桩坐标表（桩号,X,Y） | 路线分册 | 位置、走向、方位角 |
| 坐标系+投影带+中央子午线 | 图签/测量说明 | 高斯反算 |
| 跨径布置与桥梁全长 | 桥型布置图 | 墩位与分段 |
| 桥面宽度及分幅 | 横断面图 | 梁体截面 |
| 梁高变化 | 一般构造图 | 变截面梁 |
| 墩型/墩高/承台 | 下部结构图 | 桥墩建模 |
| 纵断面设计标高 | 路线纵断面 | 桥面标高曲线、净空 |
| 通航等级/净空 | 设计说明 | 主桥高度合理性 |
| 旧桥位置与拆除范围 | 施工组织/拆除图 | 新旧桥标注 |
| 现场环境 | 照片/影像 | 底图与实景融合 |

## 最低可开工包

只有以下三样也能出"石洲大桥同款"（示意级立体 + 真实底图）：

1. 施工图/初设 PDF（含平面图、桥型布置图、逐桩坐标表）
2. 坐标锚点 + 坐标系说明
3. 一句话项目说明（重建/新建、规模、旧桥是否拆除）

## 非桥梁项目（房建/园区）

简化：总平面图 + 单体平立剖 + 效果角度清单，走"真实底图 + 参数化体块 + 实景融合"。

## 边界声明

- 只有卫星影像时，建筑只能做简化体块（示意立体感），不逐栋还原造型材质。
- 要达到"高德 3D 实景建筑"级别，必须提供 B2（倾斜摄影）或 C1（真实模型）。
